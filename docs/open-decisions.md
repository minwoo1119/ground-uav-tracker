# 미결정 사항

다음 단계에 들어가기 전에 프로젝트 소유자가 결정해야 할 항목입니다.

1. 입력 소스와 배포 환경: RTSP/USB/파일 중 우선순위, 해상도·FPS, 운영체제와 GPU/Jetson 사양
2. 탐지 목표: UAV 클래스 범위, 최소 객체 크기, 오탐/미탐 우선순위 및 지연시간 목표
3. 모델과 추론 백엔드: 후보 모델, 입력 크기, 정확도 기준, ONNX/TensorRT 등 배포 형식
4. 데이터셋 정책: 사용 가능한 촬영 데이터, 라이선스, 라벨 포맷, 학습/검증/시험 분리 기준
5. 추적 요구: 단일/다중 UAV, 가림 처리, ID 유지 시간, 필요한 추적 품질 지표
6. 출력 계약: 콘솔/JSON/네트워크/GUI 여부, 좌표계, 타임스탬프 기준과 외부 시스템 연동 형식
7. 성능 구조: 동기식 유지 여부, 큐 크기와 프레임 드롭/백프레셔 정책, CPU/GPU 메모리 경계
8. 품질 도구: 포매터·정적 분석·커버리지 기준과 CI 대상 플랫폼

결정 내용을 기록한 뒤 인터페이스 변경이 필요한지 먼저 검토하고, 그 다음 어댑터와 실제 알고리즘을 추가합니다.
