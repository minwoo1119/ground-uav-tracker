# 미결정 사항

모든 항목은 현재 **TBD**입니다.

| 결정 항목 | 주요 선택지 | 영향 |
|---|---|---|
| 검출 모델과 크기 | 후보 모델 및 입력 크기 | 라이선스, 정확도, 지연시간, TensorRT 호환성 |
| 클래스 구성 | Drone/Bird 또는 추가 항공기 클래스 | 데이터 라벨, 출력 계약, 오탐 분석 |
| 입력 환경 | 파일, USB, RTSP와 카메라 사양 | 비디오 어댑터, 지연, 배포 의존성 |
| 프레임 처리 | full-frame, ROI, tiling과 추론 주기 | 소형 객체 recall, 처리량, 복잡도 |
| 추적 방식 | Kalman/association, optical flow, SOT 등 | 상태 모델, 입력 요구, 평가 지표 |
| 객체 수 | 단일 객체 우선 또는 MOT 포함 | 인터페이스 구체화, 연산량, ID 관리 |
| Jetson 스택 | JetPack/TensorRT/DeepStream 버전 | 빌드 이미지, API, 배포 방식 |
| 성능 기준 | FPS, latency, 정확도와 로그 보존 | 테스트 장비, 합격 기준, 메트릭 스키마 |
| 데이터 정책 | 데이터 후보, 클래스, 분할, 라이선스 ([검토 보고서](datasets/DATASET_REVIEW.md) 참조) | 학습 재현성, 공개 가능 범위 |
| 출력 연동 | 콘솔, 파일, 네트워크, UI | 결과 스키마와 운영 구조 |

결정 전에는 관련 구현이나 버전을 고정하지 않습니다.
